## 📚 Idea/Concepto 

El cloud híbrido es una arquitectura que integra entornos on premise y nube pública mediante interoperabilidad y orquestación de cargas de trabajo, permitiendo su ejecución coordinada sobre diferentes infraestructuras. Este modelo busca equilibrar control, cumplimiento y soberanía de datos en el entorno local con la escalabilidad y elasticidad del cloud público. Se apoya en mecanismos de portabilidad (como contenedores) que abstraen la infraestructura y permiten despliegues consistentes entre entornos. La orquestación efectiva depende de una interconexión de red robusta, típicamente mediante VPNs o enlaces dedicados, que garantizan seguridad y baja latencia entre ambos entornos. Además, habilita estrategias como cloud bursting y, aunque ofrece flexibilidad, introduce desafíos como la fragmentación de APIs entre proveedores y costos asociados al movimiento de datos (egress fees), donde transferir datos fuera de la nube puede generar costos significativos dependiendo del volumen y destino.
