## 📚 Idea/Concepto 

Proceso de verificación y validación (V&V) diseñado para asegurar que cada componente del sistema opera conforme a sus especificaciones funcionales. Se basan en técnicas de caja negra, evaluando el comportamiento observable del sistema ante entradas específicas para producir salidas esperadas, prescindiendo del conocimiento de la lógica algorítmica interna. Pueden ejecutarse de forma manual o automatizada para garantizar que el software cumple con las necesidades del usuario final definidas en los casos de uso o historias de usuario.
